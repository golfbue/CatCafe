# 🐈 NekoCafe: CatCafe Management System (Graph Database)

โปรเจกต์ระบบจัดการคาเฟ่แมวที่ใช้ **Neo4j (Graph Database)** ในการจัดการข้อมูลความสัมพันธ์ระหว่างลูกค้า แมว และออเดอร์

---

## 📂 โครงสร้างโปรเจกต์ (Project Structure)

โปรเจกต์แบ่งออกเป็น 2 ส่วนหลักที่เชื่อมต่อกัน:

### 1. Frontend (ส่วนหน้าเว็บ)
*   **เทคโนโลยี:** HTML, Vanilla CSS, JavaScript (ไม่มี React แล้ว เพื่อให้แก้ไขง่ายที่สุด)
*   **การใช้งาน:** ดับเบิลคลิกไฟล์ `.html` ในโฟลเดอร์ `frontend` เพื่อเปิดดูหน้าเว็บได้ทันที
*   **ไฟล์สำคัญ:**
    *   `index.html`: หน้าหลักลูกค้า
    *   `admin.html`: หน้า Dashboard แอดมิน
    *   `style.css`: จัดการดีไซน์ทั้งหมด
    *   `app.js`: รวมคำสั่งส่งข้อมูลไปหา Backend

### 2. Backend (ส่วนเซิร์ฟเวอร์)
*   **เทคโนโลยี:** Node.js (Express), Neo4j Driver
*   **การใช้งาน:** รันคำสั่ง `node server.js` เพื่อเปิด API
*   **ไฟล์สำคัญ:**
    *   `db.js`: เชื่อมต่อฐานข้อมูลกราฟ
    *   `seed.js`: สคริปต์สำหรับล้างข้อมูลและสร้างข้อมูลจำลองใหม่
    *   `routes/`: โฟลเดอร์เก็บ Logic ของข้อมูลแต่ละส่วน (เช่น สั่งอาหาร, จัดการแมว)

## 🚀 ขั้นตอนการติดตั้งและรัน (Setup Guide)

สำหรับเพื่อนๆ ที่รับงานไปทำต่อ ให้ทำตามลำดับดังนี้:

### ขั้นตอนที่ 1: เตรียมฐานข้อมูล
1.  ติดตั้งและเปิดโปรแกรม **Docker Desktop**
2.  เปิด Terminal ในโฟลเดอร์หลัก แล้วพิมพ์คำสั่ง:
    ```bash
    docker compose up -d
    ```

### ขั้นตอนที่ 2: เตรียม Backend
1.  เข้าไปที่โฟลเดอร์ `backend`
2.  ติดตั้ง Library: `npm install`
3.  สร้างข้อมูลจำลองลงกราฟ: `node seed.js`
4.  เริ่มรันเซิร์ฟเวอร์: `node server.js`

### ขั้นตอนที่ 3: เปิดหน้าเว็บ
1.  เข้าไปที่โฟลเดอร์ `frontend`
2.  **ดับเบิลคลิกไฟล์ `index.html`** เพื่อเริ่มใช้งาน!

## 🧠 คำแนะนำสำหรับคนทำต่อ (Contribution Tips)

*   **ถ้าอยากแก้ดีไซน์:** ให้แก้ที่ไฟล์ `frontend/style.css` (ใช้ CSS พื้นฐานทั้งหมด)
*   **ถ้าอยากเพิ่มปุ่มกดสั่งงาน:** ให้ไปเขียนฟังก์ชันใหม่ใน `frontend/app.js` แล้วใช้คำสั่ง `fetch()` ส่งข้อมูลไปที่ `http://localhost:5000/api/...`
*   **ถ้าอยากดูข้อมูลในฐานข้อมูลตรงๆ:** ให้เข้าเบราว์เซอร์ไปที่ `http://localhost:7474` (Neo4j Browser)
